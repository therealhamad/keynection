## Chrome Extension with Claude AI + Replit Integrations

---

## 1. Product Overview

**Keynection** is a Chrome extension that provides a keyboard-activated overlay for executing AI-powered actions based on browser context. Press `Cmd+K`, and Claude AI understands what you're viewing to instantly create emails, tasks, documents, and more—across 11 integrated platforms.

### Connected Integrations (Active):

✅ Discord | ✅ GitHub | ✅ Gmail | ✅ Google Calendar | ✅ Google Docs

✅ Google Drive | ✅ Google Sheets | ✅ Linear | ✅ Notion | ✅ OneDrive | ✅ Outlook

---

## 2. Tech Stack

- **Platform**: Chrome Extension (Manifest V3)
- **Frontend**: React 18 + TypeScript + Tailwind CSS
- **Build**: Vite
- **AI**: Claude 3.5 Sonnet (Anthropic)
- **Integrations**: Replit native connectors (no OAuth setup needed!)

## 3. Smart Actions (Priority Order)

### 🔥 PHASE 1: Core Actions (Week 1-2)

### 1. Email This Page/Quote (Gmail/Outlook)

**Trigger:** Article page OR text selected

**Flow:**

1. User on TechCrunch article → Press `Cmd+K`
2. "Email This Page ✨" appears first
3. Claude reads article → generates subject + body
4. Form pre-fills → User adds recipient → Send via Gmail

**Claude Prompt:**

```
Generate a professional email from this content:

Title: {pageTitle}
URL: {pageUrl}
Content: {mainContent}
Selected: {selectedText || 'N/A'}

Requirements:
- Subject: Clear, max 60 chars
- Body: 100-150 words, professional tone
- Include source URL
- If text selected, format as quote

Return JSON: {"subject": "...", "body": "..."}
```

**Replit API:** `Gmail.send()` or `Outlook.send()`

### 3. Extract Tasks → Linear/Notion (Linear + Notion)

Return JSON array: [

    "priority": "..."
  }
]

### 4. Automated Standup (GitHub + Notion + Google Calendar)

**Trigger:** "Generate Standup Update ✨"

**Flow:**

1. User clicks "Generate Standup"
2. System fetches:
    - **GitHub**: Commits (last 24h)
    - **Notion**: Completed tasks
    - **Google Calendar**: Meetings attended
3. User reviews activities (checkboxes to include/exclude)
4. Optional: Add blockers
5. Claude generates formatted standup
6. Post to Discord or copy to clipboard

**Data Collection:**

```tsx
// GitHub
const commits = await GitHub.getUserEvents(username, { since: '24h' });
const pushEvents = commits.filter(e => e.type === 'PushEvent');

// Notion
const tasks = await Notion.search({
  filter: { last_edited_time: { past_day: {} } }
});

// Google Calendar
const meetings = await GoogleCalendar.listEvents({
  timeMin: '24h ago',
  timeMax: 'now',
  minAttendees: 2
});
```

**Claude Prompt:**

```
Generate Slack-style standup from:

GitHub Commits:
{commits.map(c => `- ${c.message} (${c.repo})`).join('\\n')}

Notion Tasks:
{tasks.map(t => `- ${t.title}`).join('\\n')}

Meetings:
{meetings.map(m => `- ${m.summary} (${m.duration}min)`).join('\\n')}

Blockers: {blockers || 'None'}

Format:
*Yesterday* 🗓️
- Accomplishments (group similar commits)

*Today* 📋
- Next steps (infer from yesterday)

*Meetings* 🤝
- Concise list

*Blockers* 🚧
- If any

Use markdown, under 250 words.
```

**Output:** Post to Discord or copy to clipboard

## 5. Context Detection Logic

### What to Detect:

```tsx
interface PageContext {
  // Selection
  hasSelection: boolean;
  selectedText: string;

  // Page info
  pageTitle: string;
  pageUrl: string;
  pageType: 'article' | 'github' | 'gmail' | 'general';

  // Content
  isArticle: boolean;
  wordCount: number;
  mainContent: string; // First 3000 chars
}
```

### Detection Rules:

```tsx
// Text selection
hasSelection = window.getSelection().toString().length > 10;

// Article detection
isArticle =
  wordCount > 300 &&
  (document.querySelector('article') ||
   document.querySelector('[property="og:type"][content="article"]'));

// Page type
if (url.includes('github.com')) pageType = 'github';
if (url.includes('mail.google.com')) pageType = 'gmail';
```

### Action Suggestions Based on Context:

```tsx
// Article page + no selection
→ Show: Email This Page, Save to Notion, Save to Google Docs

// Text selected + task keywords
→ Show: Extract Tasks (Linear/Notion)

// GitHub issue page
→ Show: Create Linear Issue, Smart Comment

// Gmail thread
→ Show: Smart Reply, Schedule Meeting

// Always available
→ Show: Generate Standup, Log to Sheets
```

## 7. Claude Integration

### Setup:

```tsx
import Anthropic from '@anthropic-ai/sdk';

const anthropic = new Anthropic({
  apiKey: process.env.CLAUDE_API_KEY
});

async function generateContent(prompt: string): Promise<string> {
  const message = await anthropic.messages.create({
    model: 'claude-3-5-sonnet-20241022',
    max_tokens: 1024,
    messages: [{
      role: 'user',
      content: prompt
    }]
  });

  return message.content[0].text;
}
```

### JSON Parsing:

```tsx
function parseClaudeResponse(response: string): any {
  // Remove markdown code fences if present
  const cleaned = response
    .replace(/```json\\n?/g, '')
    .replace(/\\n?```/g, '')
    .trim();

  try {
    return JSON.parse(cleaned);
  } catch (error) {
    // Fallback: try to extract JSON from text
    const jsonMatch = cleaned.match(/\\{[\\s\\S]*\\}/);
    if (jsonMatch) {
      return JSON.parse(jsonMatch[0]);
    }
    throw new Error('Failed to parse Claude response');
  }
}
```
